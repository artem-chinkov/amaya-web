# Amaya Web

Образовательная веб-платформа Amaya Soft для дошкольников. Первый модуль помогает детям **5–7 лет** развивать речь и учиться читать на русском: от звуков и букв к слогам, словам и первым текстам.

Ребёнок осваивает навыки через короткие озвученные игры. После занятия родитель видит, с какими заданиями ребёнок справился, что стоит повторить и во что можно вместе поиграть дома.

## Статус проекта

Сейчас определяем требования и готовим первый интерактивный прототип. В репозитории собраны материалы проекта в [`docs/`](docs/). Инструкция по запуску появится вместе с кодом приложения.

## Сценарий первого прототипа

1. Ребёнок отвечает на несколько вопросов вводного теста.
2. Родитель видит предварительный результат и предложение подписки. Первое занятие доступно бесплатно.
3. Ребёнок открывает одну планету, одну зону и проходит игровой уровень с озвученными заданиями на один навык.
4. Кабинет родителя показывает результат пройденного уровня, идею для совместного занятия дома и демонстрационный статус подписки.

Пример учебной механики — услышать звук и выбрать картинку со словом, которое начинается на этот звук. Навык, слова и инструкции уточняем с методистом.

## Разработка

**Стек фронтенда:** React 19, TypeScript, Vite и Tailwind CSS.

Сначала определяем структуру данных урока и его результата, затем собираем сценарий в браузере на тестовых данных. Результат прохождения сохраняем локально и показываем в кабинете. После проверки прототипа подключаем API, базу данных, авторизацию и оплату.
